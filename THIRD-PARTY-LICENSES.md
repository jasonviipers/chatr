# Third-party licences

Chatr is built on open-source packages. Each is licensed by its authors under its own terms, which the project
licence (see `LICENSE`) does not change. This list covers the packages the two parts of the project need to run (not
the development tools), as installed on 2026-10-24. The full licence text of each is in that package's own folder.

To regenerate the list, or to collect the full licence texts into a folder:

```bash
cd api && bun x license-checker-rseidelsohn --production --excludePrivatePackages --files ../licenses/api
cd ../app && bun x license-checker-rseidelsohn --production --excludePrivatePackages --files ../licenses/app
```
